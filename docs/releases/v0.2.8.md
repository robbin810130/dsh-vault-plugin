# DSH Vault 0.2.8

This release restores Vault support for DeepSeek Harness `0.1.7-rc.1`. Vault policy now uses the DSH plugin config schema and the 0.1.7 settings form APIs. A version- and hash-pinned DSH compatibility patch adds an asynchronous session-opening gate; locked or unavailable Vault state is rejected before browser history is fetched.

The gate is a browser UI privacy control. It does not authorize remote clients at the server and does not encrypt DSH's conversation database. The DSH 0.1.7 plugin API provides a session-row action but no workspace-row accessory or dedicated denied-conversation slot.

Validation includes the DSH session-controller gate tests, Vault regression tests, typechecks, package checks, and local launcher lifecycle acceptance on macOS.
