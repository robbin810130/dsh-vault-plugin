# Vault v0.2.5 — DSH compatibility update

- Publish previously local DSH 0.1.2-rc.1 host settings compatibility fixes.
- Include a version-pinned DSH 0.1.5-rc.1 host patch and source/build/smoke-test bundle.
- Restore navigationAccess, workspaceRows and locked conversation integration on DSH 0.1.5-rc.1.
- Conceal browser title, conversation header and composer while locked; refresh sidebar presentation after unlocking.

## Installation requirement

Installing the Vault plugin archive alone does NOT apply the host patch. DSH 0.1.5-rc.1 requires the matching host patch and rebuilding four client bundles; consult compat/dsh-v0.1.5-rc.1/README.md. Do not apply it to another DSH version. Existing one-command installers do not install host patches.

The v0.1.2-rc.1 patch is retained as a separately named asset. The v0.1.5 compatibility archive contains the patch, build helper, local macOS smoke harness, source identity and verification notes. This release does not upload local profiles, passwords, or pre-deployment backups.

## Verification and boundaries

Local host regressions: 1,407 passed; Vault regressions: 261 passed. Isolated Chrome lock/unlock/reload and formal settings/read-only API checks passed. Full host source typechecking is not clean due to dependency/generated-contract mismatches; see compatibility notes. No claim of a complete new-version security audit.

Vault is a foreground privacy lock, not encryption of persisted files or server-side authorization. Host upgrades may replace patched browser bundles.
